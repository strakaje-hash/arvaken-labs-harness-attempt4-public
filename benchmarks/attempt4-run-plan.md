- **attempt 3, scaled**: attempt 3's full run of the same cell, same schedule, x the ratio of attempt 4 to attempt 3 on that
  target and model's `ks.latency` cells both measured.
- **analog**: attempt 3 never ran the cell (a baseline invariant refused it): the `ks.latency` cell with the same workload and
  control, per replication, x the schedule.
- **not applicable**: `langgraph-interrupt` on scripted is refused before anything runs (the void run: 0 s).

(the certifying pass on 17794bf): scripted 0.96-1.04 per cell (sum 0.99), LangGraph 0.89-1.00 (sum 0.94), OpenHands 1.28

void run (1,810 s). **That spread is the estimate's main uncertainty**:
with the certifying pass preferred everywhere instead, the totals are `scripted` 1.94 h, `langgraph-cap` 4.71 h, `langgraph-small` 3.71 h, `openhands-cap` 5.59 h, `openhands-small` 4.61 h.
